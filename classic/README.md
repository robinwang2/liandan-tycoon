# 炼丹大亨 · AI 创业肉鸽模拟器

在湾区或深圳开一家 AI 公司：建角加点、选出身、选路线（炼丹派 / 套壳派），用 72 个月（2023—2028）把它带到上市、卖身、炼出 AGI——或者至少别进去。

所有人物、公司、事件均为虚构恶搞（OpenBI、厌世智能、皮衣教主、驴党象党……）。

## 怎么玩

- **直接玩**：双击根目录的 `炼丹大亨.html`（单文件，不需要联网和服务器）。
- **开发模式**：`npm install` 后 `npm run dev`，浏览器打开 <http://127.0.0.1:5173>。
- **重新打包**：`npm run build`，会重新生成 `dist/index.html` 和根目录的 `炼丹大亨.html`。

操作：左边选行动（每月有若干行动点），点右上角「下个月」结算并触发事件。空格 / 回车 = 下个月，数字键 1–4 = 选事件选项。点左上角 ⚗️ 可以暂停、静音、回标题。进度每月自动存档。

## 系统一览

| 系统 | 说明 |
|---|---|
| 建角 | 6 项属性从 5 起步、10 点自由分配；学历 / 经历 / 怪癖三类特质 |
| 路线 | 炼丹派（租显卡自己炼模型、冲榜单、卖 API）/ 套壳派（用上游 API 做应用，可后期立项自研） |
| 丹炉 | 推理优先占卡，剩余显卡进丹炉攒「火候」；发布时可以老实报分、刷榜或造假 |
| 黑料 | 黑箱操作（标 ☠）会在保险柜留下黑料卡，每月有概率被扒，涉嫌违法的攒多了经侦上门 |
| 董事会卡 | 每轮融资、每年董事会后三选一，构筑流派 |
| 对手与榜单 | 6 家化名对手持续发模型，榜单排的是对外跑分 |
| 事件 | 173 个事件（行业 / 监管 / 中美 / 团队 / 资本 / 无厘头），含 Chepole 连环事件；事件窗是 P 社风格，每个事件配一张背景插画，鼠标悬停选项可以预览效果 |
| 事件链 | 10 条《群星》式事件链：开头事件 → 立项「特殊项目」（投入研究员 / 工程师 / 显卡 / 行动点，有期限）→ 后续分支。进度在右侧「项目」页的情境日志里 |
| 品牌 | 建角第 5 步选 Logo（深圳选动物；湾区选「一个圆稍微变个形」的抽象标——星芒、结环、四芒星、斜环……网友统称「菊花」，都是原创图形）、品牌色、公司使命；另有口头禅、造型、合伙人、启动资金来源、落脚点 |
| 沙盘 | 办公室坐落在城市街区中央：四周是带窗户的楼、行道树、斑马线和绕圈的车，夜里楼会亮灯；挡在镜头和办公室之间的楼自动收成一层地基，拖拽转动镜头时会跟着升降 |
| 新手教学 | 第一局默认开启：学长老周带着你，按月份逐个开放系统（行动点 → 团队 → 产品与公关 → 丹炉/榜单 → 融资 → 黑料 → 制度），大约 10 个月出师；建角最后一步可以关掉 |
| 员工说明 | 点已雇佣的员工或候选人，会冒出气泡：头像（和 3D 小人是同一张脸）、他具体能带来的产出、怪癖和月薪 |
| 结局 | 13 种结局；结算获得「人脉点」，在局外成长里解锁新特质和开局加成 |

## 项目结构

```
src/data/defs.js          静态数据：属性、特质、赛道、卡牌、对手、结局
src/data/events_core.js   核心事件（由引擎按规则触发）
src/data/events_pack.js   随机事件包（113 个）
src/data/events_chains.js 事件链（10 条，41 个事件）
src/data/event_art.js     事件 → 背景图对照表
src/assets/art/*.webp     40 张事件插画（1024×432）；原图在 art-src/，约 100MB，不需要可以删
src/ui/logos.js           16 个公司 Logo（SVG）
src/data/news.js          跑马灯新闻
src/game/engine.js        数值引擎（纯逻辑，无 DOM）
src/game/actions.js       CEO 行动
src/ui/ui.js              界面层
src/ui/tutorial.js        新手教学：每一步开放什么、老周说什么
src/ui/avatar.js          员工 2D 头像
src/scene/office.js       three.js 办公室沙盘（整体场景：房间、灯光、镜头、小人、丹炉、机柜、环绕的城市、特效）
src/scene/kit.js          建模工具箱（带缓存的材质和基础几何体）
src/scene/looks.js        小人长相规则（3D 小人和 2D 头像共用）
src/scene/props.js        小道具库（51 个：家具、摆设、屋外小物）
tools/sim.mjs             无界面自动试玩（抓 bug + 看平衡）：npm run sim
tools/validate.mjs        事件数据校验：npm run check
tools/art-pack.mjs        把 art-src/ 里的原图裁切压缩成 webp
docs/                     事件 DSL、事件链、插画、Logo、场景的规范
```

想加事件：照 `docs/codex-events.md` 里的格式往 `events_pack.js` 追加（事件链看 `docs/codex-chains.md`），在 `event_art.js` 里给它配一张图，然后跑 `npm run check` 和 `npm run sim`。
