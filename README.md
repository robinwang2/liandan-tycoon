# 炼丹大亨 · AI 创业肉鸽模拟器

在湾区或深圳开一家 AI 公司：建角加点、选出身、选路线（炼丹派 / 套壳派），用 72 个月（2023—2028）把它带到上市、卖身、炼出 AGI——或者至少别进去。

所有人物、公司、事件均为虚构恶搞（OpenBI、厌世智能、皮衣教主、驴党象党……）。

## 两个版本

| 文件 | 说明 |
|---|---|
| `炼丹大亨-3A.html` | **3A 版**：微缩景观电影感画面（PBR 材质、环境光遮蔽、景深、泛光、调色）、昼夜与天气、深色玻璃风格界面、线性图标、合成音效 + 环境声 + 生成式配乐、画质与声音设置 |
| `炼丹大亨-经典版.html` | **经典版**：原来的低模卡通沙盘 + 卡通贴纸界面，源码原样保存在 `classic/` |

两个版本的事件和主要数值一样，存档也通用（都存在浏览器里）。3A 版另外多了：行动提示、显卡超出配额按现货价租、办公室从 5 档扩到 8 档（多层办公楼）。3A 的存档拿到经典版继续时，办公室最多按总部大楼算。

## 怎么玩

- **直接玩**：双击上面任意一个 html（单文件，不需要联网和服务器）。3A 版建议用独立显卡；卡的话点右上角齿轮把画质调低（默认开着「自动调整」，卡顿时会自动降一档）。
- **开发模式**：`npm install` 后 `npm run dev`，浏览器打开 <http://127.0.0.1:5173>（3A 版）。
- **重新打包**：`npm run build` 生成 `炼丹大亨-3A.html`；`npm run build:classic` 重新生成经典版。

操作：左边选行动（每月有若干行动点），点右上角「下个月」结算并触发事件。空格 / 回车 = 下个月，数字键 1–4 = 选事件选项，Esc 关窗。点左上角公司 Logo 可以暂停、静音、回标题；齿轮是画质与声音设置。进度每月自动存档。沙盘可以拖拽转动、滚轮缩放。

## 系统一览

| 丹炉 | 推理优先占卡，剩余显卡进丹炉攒「火候」；发布时可以老实报分、刷榜或造假 |

| 显卡配额 | 配额以内按市价租，配额随融资轮次上涨，找皮衣教主、高价扫货和一些事件也能加；超出配额也能租，按现货价算，租得越多越贵（市价 2 倍起） |
| 黑料 | 黑箱操作（标 ☠）会在保险柜留下黑料卡，每月有概率被扒，涉嫌违法的攒多了经侦上门 |
| 董事会卡 | 每轮融资、每年董事会后三选一，构筑流派 |
| 对手与榜单 | 6 家化名对手持续发模型，榜单排的是对外跑分 |
| 事件 | 173 个事件（行业 / 监管 / 中美 / 团队 / 资本 / 无厘头），含 Chepole 连环事件；事件窗是 P 社风格，每个事件配一张背景插画，鼠标悬停选项可以预览效果 |
| 事件链 | 10 条《群星》式事件链：开头事件 → 立项「特殊项目」（投入研究员 / 工程师 / 显卡 / 行动点，有期限）→ 后续分支。进度在右侧「项目」页的情境日志里 |
| 品牌 | 建角第 5 步选 Logo（深圳选动物；湾区选「一个圆稍微变个形」的抽象标——星芒、结环、四芒星、斜环……网友统称「菊花」，都是原创图形）、品牌色、公司使命；另有口头禅、造型、合伙人、启动资金来源、落脚点 |
| 新手教学 | 第一局默认开启：学长老周带着你，按月份逐个开放系统，大约 10 个月出师；建角最后一步可以关掉 |
| 行动提示（3A 版） | 顶部居中一排待办提醒。红色是急事：快没钱、显卡不够推理、项目要超期、对赌到期、经侦盯上；金色是机会或闲置：功能上线了该开下一个、丹炉可以出炉、能融下一轮、工位坐满、缺研究员；蓝色是隐患：监管、黑料曝光概率、996、热度、口碑。点一下直接去做，做不了的会切到对应页签、把按钮闪给你看；点 × 暂时不提醒。左边行动卡会标「建议」，页签上有小金点，底部的产品和丹炉小部件也能直接点。还剩行动点时按「下个月」，确认框里会列出最值得做的事。设置里可以关掉 |
| 员工说明 | 点已雇佣的员工或候选人，会冒出气泡：头像（和 3D 小人是同一张脸）、他具体能带来的产出、怪癖和月薪 |
| 结局 | 13 种结局；结算获得「人脉点」，在局外成长里解锁新特质和开局加成 |

## 3A 版的画面和声音

- **城市**：办公室坐落在街区中央，周围的街区按地区和公司规模生成——深圳从城中村一路搬到 CBD，湾区从维多利亚小楼搬到科技园。楼有真的窗洞、窗框、阳台、空调外机、屋顶水塔，底层是带店招的商铺；路上有车流、行人、红绿灯、公交站、小吃摊。挡在镜头和办公室之间的楼会被「剖开」只留底层，转动镜头时跟着变。
- **时间和天气**：每个月的时段和天气不同（湾区多雾，深圳夏天多雨），翻月时会播一段延时摄影；开了 996 就是深夜，整座城亮起灯来。
- **办公室**：前四档是单层剖面房间，五档起是多层办公楼：看某一层时，下面的楼层是玻璃幕墙，上面的先拿掉；「全楼」总览能看到整栋楼、楼顶招牌和每层的部门牌，切楼层时镜头跟着观光电梯上下，到站「叮」一声。房间里有工位、机房、玻璃会议室、茶水间、八卦石台上的青铜丹炉；出炉发布时炉盖会被金光顶开。
- **渲染**：PBR 材质 + 程序化微表面（木纹、布纹、拉丝金属、沥青颗粒、地砖缝）、天空与环境反射、环境光遮蔽、按焦点虚化的景深（微缩模型感）、泛光、电影调色。静态物体按质感合批，楼和小人用 BatchedMesh，整座城只有几百次绘制。
- **画质档位**：七档，从「手机」到「极致」。
  - 手机：不走后期、直接出画面，不开阴影，室内点光源关掉，城市只留近处，默认锁 30 帧。手机上会自动选这档；请横屏玩，可以双指捏合缩放。
  - 极简 / 流畅 / 均衡 / 高 / 电影：和原来一样，阴影、环境光遮蔽、景深逐档加上去。独显默认「高」，核显默认「流畅」。
  - 极致：原生 4K、8K 软阴影、满分辨率遮蔽、城市实时反射（在楼顶上方拍一圈街景做环境贴图）、多一圈街区、更多车和行人。
  - 设置里还能调「渲染精度」（50%–150%）和「帧率上限」（跟随画质 / 30 / 60 / 不限）。每档都限制了内部渲染像素，2K/4K 屏不会硬算原生分辨率，界面依然清晰。
- **声音**：全部用 WebAudio 现场合成（不带任何音频文件）：二十多种界面音效、跟着昼夜天气和人数变化的环境声、按局势切换情绪的生成式配乐。

## 项目结构

```
src/data/            静态数据、事件（核心 / 随机包 / 事件链）、事件插画对照表、新闻
src/game/engine.js   数值引擎（纯逻辑，无 DOM）
src/game/actions.js  CEO 行动
src/game/advice.js   行动提示（参谋）：根据局面算出现在最该做的几件事（纯逻辑，自动试玩也用它）
src/ui/ui.js         界面层
src/ui/tutorial.js   新手教学：每一步开放什么、老周说什么
src/ui/icons.js      界面线性图标（87 个，原创 SVG）
src/ui/logos.js      16 个公司 Logo（SVG）
src/ui/avatar.js     员工 2D 头像
src/audio/audio.js   音频引擎：合成音效、环境声、生成式配乐
src/hud.css          3A 版界面皮肤（深色玻璃），叠在 style.css / pdx.css / extra.css 上面
src/scene3a/stage.js 舞台：渲染器、后期管线、天空昼夜天气、镜头
src/scene3a/kit.js   建模工具箱：PBR 材质与微表面、几何体、静态合批、BatchedMesh 合批
src/scene3a/city.js  城市生成（分帧异步生成，切换时不卡顿）
src/scene3a/office.js 办公室（单层房间和多层办公楼、电梯）、小人、丹炉、特效
src/scene3a/props.js 高精度道具库（111 个：家具、街道设施、车辆、屋顶设备、树）
src/scene3a/index.js 3A 场景入口（对外接口和经典版一样）
src/scene/           经典版的场景代码（looks.js 两个版本共用）
classic/             经典版完整源码快照
tools/sim.mjs        无界面自动试玩（抓 bug + 看平衡 + 检查行动提示，另有一个「先照提示做事」的机器人做对照）：npm run sim
tools/validate.mjs   事件数据校验：npm run check
tools/props-check.mjs   道具库自检；tools/audio-check.mjs 音频引擎自检
docs/                事件 DSL、事件链、插画、Logo、场景、道具、音效、界面的规范
```

想加事件：照 `docs/codex-events.md` 里的格式往 `events_pack.js` 追加（事件链看 `docs/codex-chains.md`），在 `event_art.js` 里给它配一张图，然后跑 `npm run check` 和 `npm run sim`。
