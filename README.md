# 炼丹大亨 · AI 创业肉鸽模拟器

在湾区或深圳开一家 AI 公司：建角加点、选出身、选路线（炼丹派 / 套壳派），用 72 个月（2023—2028）把它带到上市、卖身、炼出 AGI——或者至少别进去。

所有人物、公司、事件均为虚构恶搞（OpenBI、厌世智能、皮衣教主、驴党象党……）。

## 两个版本

| 文件 | 说明 |
|---|---|
| `炼丹大亨-3A.html` | **3A 版**：微缩景观电影感画面（PBR 材质、环境光遮蔽、景深、泛光、调色）、昼夜与天气、深色玻璃风格界面、线性图标、合成音效 + 环境声 + 生成式配乐、画质与声音设置 |
| `炼丹大亨-经典版.html` | **经典版**：原来的低模卡通沙盘 + 卡通贴纸界面，源码原样保存在 `classic/` |

两个版本的事件和主要数值一样，存档也通用（都存在浏览器里）。3A 版另外多了：行动提示、显卡配额跟着采购走（不再跟融资轮次绑定，超出配额按现货价租）、办公室从 5 档扩到 8 档（多层办公楼）、「意识形态」页和「路线之争」事件链。3A 的存档拿到经典版继续时，办公室最多按总部大楼算。

## 怎么玩

- **直接玩**：双击上面任意一个 html（单文件，不需要联网和服务器）。3A 版建议用独立显卡；卡的话点右上角齿轮把画质调低（默认开着「自动调整」，卡顿时会自动降一档）。
- **开发模式**：`npm install` 后 `npm run dev`，浏览器打开 <http://127.0.0.1:5173>（3A 版）。
- **重新打包**：`npm run build` 生成 `炼丹大亨-3A.html`（会先把表格导出一遍）；`npm run build:classic` 重新生成经典版。
- **改数值、改文案**：不用碰代码，改 `tables/` 里的表格，见下面「表格」一节。

操作：左边选行动（每月有若干行动点），点右上角「下个月」结算并触发事件。空格 / 回车 = 下个月，数字键 1–4 = 选事件选项，Esc 关窗。点左上角公司 Logo 可以暂停、静音、回标题；齿轮是画质与声音设置。进度每月自动存档。沙盘可以拖拽转动、滚轮缩放。

## 3A 版的画面和声音

- **城市**：办公室坐落在街区中央，周围的街区按地区、落脚点和公司规模生成——起步时六个落脚点各是各的街区（郊区独栋、红砖阁楼、大学城、握手楼、科技园、电子市场），店招、行道树、路边停的车、人行道上的零碎和行人多少都不一样；公司做大以后，深圳一路搬到 CBD，湾区搬到科技园。楼有真的窗洞、窗框、阳台、空调外机、屋顶水塔，底层是带店招的商铺；路上有车流、行人、红绿灯、公交站、小吃摊。挡在镜头和办公室之间的楼会被「剖开」只留底层，转动镜头时跟着变。
- **时间和天气**：每个月的时段和天气不同（湾区多雾，深圳夏天多雨），翻月时会播一段延时摄影；开了 996 就是深夜，整座城亮起灯来。
- **办公室**：前四档是单层剖面房间，五档起是多层办公楼：看某一层时，下面的楼层是玻璃幕墙，上面的先拿掉；「全楼」总览能看到整栋楼、楼顶招牌和每层的部门牌，切楼层时镜头跟着观光电梯上下，到站「叮」一声。房间里有工位、机房、玻璃会议室、茶水间、八卦石台上的青铜丹炉；出炉发布时炉盖会被金光顶开。
- **渲染**：PBR 材质 + 程序化微表面（木纹、布纹、拉丝金属、沥青颗粒、地砖缝）、天空与环境反射、环境光遮蔽、按焦点虚化的景深（微缩模型感）、泛光、电影调色。静态物体按质感合批，楼和小人用 BatchedMesh，整座城只有几百次绘制。
- **画质档位**：七档，从「手机」到「极致」。
  - 手机：不走后期、直接出画面，不开阴影，室内点光源关掉，城市只留近处，默认锁 30 帧。手机上会自动选这档；请横屏玩，可以双指捏合缩放。
  - 极简 / 流畅 / 均衡 / 高 / 电影：和原来一样，阴影、环境光遮蔽、景深逐档加上去。独显默认「高」，核显默认「流畅」。
  - 极致：原生 4K、8K 软阴影、满分辨率遮蔽、城市实时反射（在楼顶上方拍一圈街景做环境贴图）、多一圈街区、更多车和行人。
  - 设置里还能调「渲染精度」（50%–150%）和「帧率上限」（跟随画质 / 30 / 60 / 不限）。每档都限制了内部渲染像素，2K/4K 屏不会硬算原生分辨率，界面依然清晰。
- **声音**：全部用 WebAudio 现场合成（不带任何音频文件）：二十多种界面音效、跟着昼夜天气和人数变化的环境声、按局势切换情绪的生成式配乐。
- **危机时刻**：快没钱、经侦要上门、监管要动手、董事会要政变、士气崩了、路线之争的股权守不住、反共压力爆表……分两级。「紧张」时屏幕边缘的红光慢慢呼吸，配乐转紧张；「危急」时红光急促闪烁、多一道边框，拉一声警报，配乐换成危机曲（减三和弦铺底、心跳一样的八分音符低音、秒针滴答，每四小节一声上行警报），办公室亮起警灯。光的颜色跟着意识形态主题换：苏联风本来就满屏红，警报改成琥珀色、边框琥珀和红交替闪；社区合作社风是玫瑰红；冷色科技风是红光加扫描线。系统开了「减少动态效果」时只亮不闪。
- **换装过场**：路线之争走完、结局窗弹出时，整套界面当场换装：深圳走共产 → 从屏幕中间烧起来，火圈往外烧，烧掉的旧界面底下是苏联风；两地的资本结局 → 一道青色扫描线从上往下扫过，旧界面一行行变成冷色科技风；湾区共享繁荣 → 从中间长出藤蔓，开出玫瑰，慢慢盖过旧界面。读档、开新局直接换，不放过场；系统开了「减少动态效果」也不放。换装后配乐的主旋律也换音色：苏联风是铜管味的锯齿波加军鼓，社区合作社风是短促的拨弦加沙锤，冷色科技风是方波合成器加电子踩镲。

**怎么改**

1. 打开表，改，保存。每本表的第一张「#说明」写着每张表是什么、每种格子怎么填。
2. 运行 `npm run tables`：把表导出成游戏读的 `src/data/tables/*.json`，顺便查错。填错了会报「哪本表 › 哪张表 › 第几行 › 哪一列」，并且一个文件都不写。
3. `npm run dev` 开着的话马上能看到；`npm run build` 打包前会自动导出一遍。

**约定**

- 表头三行别动：第 1 行中文列名，第 2 行程序用的字段名，第 3 行类型。数据从第 4 行开始。
- 列名以 `#` 开头的是备注列，程序不读（想加自己的备注列，把列名写成 `#` 开头）；表名以 `#` 开头的整张表不读；第一格以 `#` 开头的行是注释。
- 别合并单元格，数据列里别写公式。
- 「效果」「条件」「修正」这几类列用一种简短写法，一个格子里写若干小项，空格隔开，先后顺序就是执行顺序：
  - 效果：`现金+8 股权-7 热度+15 标记:agi_claim 临时:收入×1.12/6月`
  - 条件：`月份≥4 地区:深圳 无标记:red,rose`
  - 检定：`口才 14`（属性检定）或 `55%`（看运气）
  - 全部关键字列在每本表的「#说明」里；中文关键字和英文字段名都认。
- id（标识）会被别的表和代码引用。名字、数值、文字随便改；改 id 之前先搜一下谁在用。
- xlsx 是二进制文件，git 里看不出改了什么。导出的 JSON 也进 git，要看改动就看它的 diff。

**加一个随机事件**：在 `事件.xlsx` 的「随机事件」加一行，在「随机选项」加 2~4 行（「事件」列填它的 id，「序号」从 1 排），「插画」填图库里的名字，然后 `npm run tables` 和 `npm run sim`。写法规范还是看 `docs/codex-events.md`（事件链看 `docs/codex-chains.md`）。

**系统事件**（账上没钱、监管重锤、对赌到期……）背后有代码：文字和数字在表里，选项什么时候出现、选了以后具体怎么算在 `src/data/events_core.js` 里，两边靠选项的「脚本」列对上。表里的文字、检定难度、效果、「参数」都可以改；「脚本」的名字别改。

**对拍**：`npm run parity` 用固定的随机种子让机器人打 144 局，把每个月的状态、每个对话框、每段文字的指纹和 `tools/parity/baseline.json` 比较。只想调整代码结构、不想改变游戏行为的时候，用它确认「一个数、一个字都没变」。故意改了数值或文案之后它当然会不一样，确认改动符合预期后用 `node tools/parity.mjs record` 重录基线。

**行动**（「启动融资」「画饼大会」……）和系统事件一样背后有代码：什么时候能点、具体怎么算在 `src/game/actions.js` 里，按行动 id 和表格对上。表里的名字、行动点、冷却、检定难度、效果、「参数」、按钮说明和全部文字都可以改；按钮说明里的 {名字} 是代码算好的数，「参数」里的数也都能这样引用。

**留在代码里的**：只有逻辑本身（怎么算、什么时候触发），以及几样不算「内容」的东西：随机数、金额和日期的格式、存档兼容、开发用的报错信息、按钮和页签对应哪一步教学、候选人岗位的抽取顺序（改了会让同一个种子打出不一样的局）。

**查错**：`npm run tables` 导出以后会跑 `tools/validate.mjs`。除了检查事件的写法，还会把 `文本.xlsx` 和代码对一遍（`tools/textcheck.mjs`）：代码要的键表里都有、每段字（两地说法都算）里的 {变量} 代码都会填、表里没人用的键提醒一下。报错会说在哪本表、哪张表、哪个 id。

**改表结构**（加列、调列的顺序）：改 `tools/tables/schema.mjs`，再用 `node tools/tables/build-xlsx.mjs --force` 从 JSON 重新生成表格。注意它会整本覆盖，手工加的备注列和调过的列宽会丢。只是给某张表加一个纯数据的列不用这么麻烦：直接在表里加一列，填好表头三行，导出的数据里就会多出这个字段。
