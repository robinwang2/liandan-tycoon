## 〇、玩法背景（写文案要知道的机制）

- 只在深圳开局出现：融资时选了「深创头：国资入股」，国资派驻董事吴建设进场，事件链开始。每个月一级，共 15 级（约 15 个月）。
- 两条进度条：**共产**（初始 12）和**资本**（初始 28），各 0~100。每个选项通过 `bars` 推动它们。
- 第 15 级选完结算：共产条满或比资本条多 → 红色结局（公司目标变成「为了共产主义乌托邦而制造 AGI」，界面换苏联风，以后拿不到西方融资）；资本条满或更多 → 「警惕不现实的乌托邦主义」，公司目标变保守，然后处置「共产倾向员工」。终局时创始人股权须 ≥ 40%，否则「你说了不算」，这条路没走成。
- 从第 3 级起，引擎会揣摩玩家想走哪条路，给他更多同类型的选项（本级 `opts` 不够的从 `IDEO_POOL` 抽）。所以卡池必须够厚，每种类型都要有大量「随时能用」的卡，也要有一批「看局势才出现」的卡。
- 玩家每级只看到 3~4 个选项，**选项文案要能独立成立**，不依赖同一级的其它选项。

## 三、IDEO_POOL：卡池（至少 46 张）

- 数量：**red ≥ 18、cap ≥ 18、mid ≥ 10**。`id` 全局唯一（snake_case）。
- 每张卡写 `from` / `to`（大多数 3~15；少数只适合前期 3~8 或后期 9~15）。
- **至少一半的卡要有 `when` 条件**，让选项「看局势」：缺钱（`runwayMax: 4`）、钱多（`runwayMin: 12`）、士气低 / 高（`moraleMax` / `moraleMin`）、热度高、口碑低、监管压力高、泡沫高、有黑料（`dirtMin`）、员工多（`staffMin`）、股权低（`equityMax: 45`）、某条进度条已经很高或很低（`redMin` / `redMax` / `capMin` / `capMax`）、自研模型（`ownModel: true`）、996（`policy: { work: '996' }`）等等。条件要和卡的内容对得上（例如「向国资股东求援」只在缺钱时出现）。
- 每种类型里都要有至少 4 张不带条件、3~15 级都能出现的「万能卡」。
- 可以有少量检定卡（`check`）或概率卡（`odds`），结果里也可以带 `bars`。

## 四、数值规范

- `bars`：主方向 +6~+12（第 15 级可到 +15），反方向 0~-4；mid 卡两边各 0~+3，或者都不动。
- 红色卡的典型代价 / 收益：士气、口碑上升，监管压力下降；花钱、热度下降、限时降低 `raiseMult` / `revMult`、限时提高 `costMult`。资本卡反过来：进钱、热度和泡沫上升、限时提高 `revMult` / `raiseMult` / `devMult`；士气和口碑下降、监管压力上升，偶尔留黑料（如 `overwork`）。mid 卡效果小而实在。
- fx 量级：`cash` -3~+4（单位是「一个月支出」），`morale` ±4~12，`hype` ±3~12，`rep` ±3~10，`reg` ±3~12，`bubble` ±2~6，`quota` ±10~30，`usersPct` ±5~15，`quality` ±2~6，`equity` -3~+3（少用），`temp` 6~12 个月，`ap` ±1（少用），`attr` ±1（很少用）。每个选项 1~4 个效果，别全是正面。
- 新增的黑料类型可以用：`unfair_fire`（违法辞退）、`fake_plan`（虚报计划完成）、`bci_lab`（秘密人体实验）。
- 新增的 when 键：`redMin` `redMax` `capMin` `capMax` `equityMin`。

- `cap`：「警惕不现实的乌托邦主义」。正文 150~250 字：大会否决了「乌托邦路线」，公司目标变得保守、警惕——稳健经营、警惕泡沫、先活下来再谈 AGI；钱满仓起草了一份《关于警惕不现实的乌托邦主义的通知》。2~3 个风味选项，效果小。
- `purge`：紧接着 cap 结局弹出，决定「共产倾向员工」的去留。正文 100~180 字（人数由引擎在正文后面补一句，你不用写数字）。四个选项的 `act` 已定，引擎执行：`fire_all` 全部开除（死忠也不例外，不给补偿，留黑料「违法辞退」）、`reeducate` 留下转岗培训（读书会解散）、`release` N+3 体面送走（死忠的可以留下）、`tolerate` 随他们去（读书会转入地下，之后可能出事）。你写 `label`（可微调）、`hint`、结果 `text`，`fx` 留空或给一点点额外效果。
- `fail`：终局时股权不到四成，大会上你说了不算，吴建设和其他股东替你定了调。正文 120~200 字，1~2 个选项，效果小。

## 六、两条一次性事件链（`UTOPIA_EVENTS` / `BCI_EVENTS`）

格式和 `src/data/events_chains.js` 完全一样：每个事件带 `chain`、`art`、`weight: 0`；用 `project` / `follow` / `chain` fx 串起来；每个结局带 `chain: { done: true }`。项目 `fail` 必须指向存在的事件。

1. **乌托邦社区实验**（`chain: 'utopia'`，红色结局后解锁，玩家花 2 亿开启）。开头事件 id 必须是 `utopia_1`（引擎在玩家付钱后直接排进来）。5~6 个事件、1~2 个特殊项目（kind 用 `ops` / `ap` / `biz`）。梗概：在城郊盖一座让 {model} 做计划的公社 → 第一次按需分配，三千人都申请了湖景房 → 游客比社员多，公社变成网红打卡点 → {model} 为了算清账本偷偷发明了「算力券」（计划着计划着又长出了市场）→ 结局。**成功结局带 `flag: 'utopia_ok'`**（引擎给长期加成：增长、口碑、士气），失败结局带 `flag: 'utopia_fail'`。两种结局都要讽刺得有分寸。
2. **脑机实验**（`chain: 'bci'`，资本结局后解锁）。开头事件 id 必须是 `bci_1`。4~6 个事件、1~2 个特殊项目（kind 用 `res` / `eng` / `legal`）。梗概：地下二层的「秘密实验部」，给自愿（真的自愿吗？）的员工戴上脑机头盔，让他们睡觉时帮丹炉算梯度 → 第一次连接，有人梦见了反向传播 → 副作用（梦话是 Python、白天走路按 batch 走）→ 结局。**成功结局带 `flag: 'bci_ok'`**（引擎：从此员工也能提供算力），叫停结局带 `flag: 'bci_shut'`。至少一个选项再加一点黑料 `{ type: 'bci_lab', sev: 6 }`。不写血腥、不写伤残，荒诞为主。
