# 任务：为《炼丹大亨》做一个低模「小道具库」

《炼丹大亨》的 3D 办公室沙盘正在重做：整体场景（房间、灯光、小人、丹炉、机柜、镜头）由别人负责，**你只负责小道具**——那些摆在办公室里和屋外的小物件。
画风：明亮、圆润、玩具感的低多边形（参考 Two Point Hospital 的家具），比例略夸张，从等距视角远看也要一眼认得出是什么。

只允许创建/修改这 3 个文件（别动其它文件，有人在同时改）：
1. `src/scene/props.js` — 道具库
2. `src/scene/props-demo.js` + 根目录 `props-demo.html` — 检查页

## 必须用的建模工具箱

先读 `src/scene/kit.js`（很短）。所有道具都用它提供的函数来建：`k.group / k.box / k.cyl / k.ball / k.cone / k.torus / k.mat / k.geo / k.put`，这样材质和几何体会被缓存复用。
需要特殊形状（旋转体、挤出体）时，用 `k.geo('唯一的 key', () => new k.THREE.LatheGeometry(...))` 建几何体，再用 `k.put(geometry, 颜色, 父节点, x, y, z, 选项)` 放置。
**不要** 自己 `new THREE.MeshStandardMaterial`，不要引入除 three 以外的依赖，不要用贴图文件。

注意工具箱的约定：坐标是 **物体中心**；单位≈米。

## 接口

```js
// src/scene/props.js
export const PROPS = {
  pingpong: {
    size: [2.8, 1.6, 0.9],            // 占地 [宽 x, 深 z, 高 y]，实际模型不能超出
    build(k, o = {}) {                 // o.brand 是公司品牌色（十六进制字符串，可能没有）
      const g = k.group();
      // ... 往 g 里加东西
      return g;                        // 原点在占地矩形的「地面中心」：y=0 是地板，正面朝 +z
    },
  },
  // ...
};
```
- 需要简单循环动画的道具（招财猫挥手、鱼缸里的鱼、风扇）可以设 `g.userData.tick = (t, dt) => { ... }`，场景每帧会调用（t 是累计秒数）。只做轻量的变换，不要每帧新建对象。
- 夜景时场景会把自发光材质调亮，所以灯、屏幕、霓虹这类东西请用 `k.mat(color, { glow: color, glowK: 0.6 })` 这样的自发光材质。
- 每个道具控制在 ~40 个网格以内；别做小于 5 厘米的细节（远看是噪点）。

## 检查页

`props-demo.html`（根目录，`<script type="module" src="/src/scene/props-demo.js">`）：浅色背景，等距正交镜头，把所有道具按 8 列网格摆在一块地板上，每个道具下面用一个朝向镜头的文字精灵写上 key；一盏方向光加柔和阴影；可以拖拽旋转、滚轮缩放；动画道具要在动。页面顶部一个按钮切换白天/夜晚（夜晚把环境光调暗，让自发光材质显出来）。
