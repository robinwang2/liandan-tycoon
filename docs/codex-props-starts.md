# 任务：给《炼丹大亨》3A 版的道具库加 26 个小道具（不同开局的差异化摆设）

背景：游戏开局可以选六个落脚点（帕洛阿尔托车库、旧金山阁楼、大学城合租屋、南山科技园、华强北、城中村握手楼）和四条产品赛道。
整体场景（房子、街区、镜头、灯光）由别人在写，会按落脚点摆不同的东西。你只负责往道具库里**追加**下面这些小道具。

只允许修改：`src/scene3a/props.js`、`tools/props-check.mjs`、`src/scene3a/props-demo.js`（如果演示页按名字分类，就把新道具归进去）。
**别动其它任何文件**（有人在同时改 `office.js` / `city.js` / `kit.js`）。不要改已有道具的名字、尺寸和造型。

## 约定（和库里已有的道具完全一致，先读 `src/scene3a/props.js` 开头的工具函数和几个现成道具，再读 `docs/codex-props3a.md`）
- `PROPS[name] = prop([宽x, 深z, 高y], (k, g, o) => {…})`，原点在**底面中心**，正面朝 **+Z**，世界单位≈米。人物是 Q 版（站立高约 1.3）。
- 画面方向：微缩景观 + 电影感。PBR 材质：几乎每个 `k.mat` 都给合适的 `rough` / `metal` / `tex`；几乎所有硬表面带倒角 `r`（哪怕 0.008）。
- `o.brand` 品牌色点缀；`o.seed` 整数，做确定性的变化（用文件里的 `hash(seed, salt)`，**不许用 Math.random**）。
- 发光的东西用 `night`：`k.mat(c, { glow, glowK, night })` 或文件里的 `lit(k, color)`。
- 会动的零件放进 `dynamic(k, g, name, …)` 子组，动画写 `g.userData.tick = (t, dt) => {…}`，只能改 dynamic 子组。动画要克制。
- 不要贴图、不要灯光对象、不要 `new THREE.xxxMaterial`。一个道具里不同材质尽量少（同色同质感复用同一个 `k.mat` 调用）。
- 三角面预算：小摆设 ≤ 6000，家具/街道设施 ≤ 15000，树 ≤ 14000。
- 不要出现任何真实品牌、真实 Logo、真实国旗；文字一律用小色块/细线条示意。

## 自测（必须做）
`tools/props-check.mjs` 里有一张 `expected` 名字→尺寸表和按名字给的三角面预算、包围盒特例：
- 把这 26 个新道具加进 `expected`；小摆设（`picket_fence` `news_rack` `kick_scooter` `guitar_stand` `pizza_stack` `string_lights` `led_ticker` `shoe_rack` `manhole_steam` `road_barrier` `hand_truck`）归进小摆设预算，其余按家具预算，`lemon_tree` 按树。
- `string_lights` 是悬挂道具（像 `pendant_lamp`：顶边 y=0、往下垂，且贴墙 z≥0）；`led_ticker`、`fire_escape` 是贴墙道具（z 从 0 起往 +Z）。在 `within()` 里给它们加上对应的包围盒特例。
- 跑 `node tools/props-check.mjs`，必须输出 `PROPS OK 137`（原来 111 个 + 26 个）。
