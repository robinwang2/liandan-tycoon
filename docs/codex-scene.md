# 任务：为《炼丹大亨》写 three.js 低模卡通办公室沙盘

《炼丹大亨》是一款 AI 创业模拟经营游戏（回合制）。UI 是 DOM 浮层，你负责背后那块 **全屏 3D 场景**：
一个等距视角的「玩具盒子」办公室沙盘，随着公司成长从车库/城中村出租屋一路升级到总部。
画风：**明亮、圆润、低多边形、玩具感**（参考 Two Point Hospital / Monument Valley 的配色干净度），带一点讽刺的小细节。

只创建/修改这 3 个文件（别动其它文件）：
1. `src/scene/office.js` — 场景模块（只允许 `import * as THREE from 'three'` 和 `three/addons/*`，不用任何外部模型/贴图/字体文件，全部程序化生成）
2. `src/scene/demo.js` + 根目录 `scene-demo.html` — 独立测试页（见文末）

three 版本是 r187（已装在 node_modules）。

## API（必须严格一致，游戏主程序按这个调用）

```js
import { createOffice } from './scene/office.js';
const office = createOffice(containerEl);   // 在 containerEl 里创建 canvas，铺满它，自带 ResizeObserver 和 rAF 循环

office.sync(view);        // 幂等：传入完整视图，内部做 diff，只增删改变化的东西。会被频繁调用。
office.play(name, data);  // 一次性特效
office.setInsets({ left, right, top, bottom });  // 像素。UI 面板挡住了四周，沙盘要居中并完整显示在剩余矩形里
office.dispose();
```

### view 结构
```js
{
  mode: 'title' | 'play',        // title：标题/建角界面，镜头缓慢自动环绕；play：经营中
  region: 'bay' | 'sz',          // 湾区 / 深圳，决定远景和装修细节
  level: 1,                      // 办公室等级 1~5
  sign: '混沌智能',               // 公司名，做成招牌/Logo 墙（CanvasTexture，中文）
  staff: [ { id: 'e12', role: 'res', mood: 72 }, ... ],   // 0~36 人；role: res 研究员 | eng 工程师 | ops 运营 | biz 商务 | legal 法务
  racks: 3,                      // 机柜数量 0~12（服务器机柜，LED 闪烁）
  furnace: null | { heat: 0.6 }, // 是否正在「炼丹」（训练模型）：null 熄火；heat 0~1 越大火越旺
  night: false,                  // true = 996 加班模式：夜景、窗外天黑、办公室灯火通明
  alert: false,                  // true = 现金告急：角落红色警灯缓慢旋转
}
```

### play 特效
| name | data | 效果 |
|---|---|---|
| `confetti` | — | 彩带礼花从屋顶喷出（发布成功/融资到账） |
| `money` | — | 钞票/金币雨 |
| `alarm` | — | 全场红光闪 3 秒 + 轻微镜头抖动（丑闻爆了） |
| `boom` | — | 丹炉炸了：黑烟 + 镜头抖动 + 小人吓一跳 |
| `levelup` | — | 办公室升级：整个沙盘弹性缩放一下 + 星星粒子 |
| `say` | `{ text, who }` | 头顶冒一个对话气泡 3.5 秒。who: `'founder'` 或员工 id，缺省随机一名员工 |
| `cameo` | `{ text }` | **长发眼镜男乱入**：一个长发及肩、戴黑框眼镜、穿格子衫的小人从屏幕外跳进沙盘正中，原地蹦三下，头顶大号气泡显示 text，停留约 5 秒后跳走。动作要夸张好笑 |

气泡用 Sprite + CanvasTexture 画（圆角白底、深色描边、中文粗体、自动换行，最多约 16 字/行）。

## 画面要求

**镜头**：OrthographicCamera 等距视角（水平 45°，俯角约 35°）。拖拽可水平环绕（限制在默认角度 ±70°），滚轮缩放（限制范围），松手后不用回弹。play 模式有极轻微的呼吸感摆动；title 模式缓慢自动环绕。沙盘始终按 `setInsets` 留出的矩形自适应居中、完整可见。

**背景**：canvas 不透明，自己画天空——竖向渐变（白天：#bfe6ff → #fef3d6；夜晚：#1b2350 → #3a2b63）+ 几朵缓慢飘动的低模云（夜晚换成星星和月亮）。
远景放在沙盘后方（会被部分 UI 挡住没关系）：
- `bay`：一座红色悬索桥剪影 + 起伏的小山丘 + 几棵棕榈树 + 一缕雾
- `sz`：一簇高矮不一的摩天楼（其中一栋尖顶的最高）+ 塔吊 + 一排握手楼

**沙盘底座**：一块有厚度的圆角「蛋糕」底座（草地/人行道边缘），办公室是切开屋顶的剖面盒子：地板 + 后面两堵墙（带窗户，窗外能看到天色），前面两侧开放。柔和阴影（PCFSoftShadowMap，一盏方向光 + 半球光）。材质用 `MeshStandardMaterial({ flatShading: true })` 或 Lambert，配色清爽饱和。

**五个等级**（地板尺寸逐级变大，工位数至少 4 / 8 / 14 / 22 / 34，必须能坐下所有 staff）：
1. `bay`：车库——水泥地、半开的卷帘门、堆在角落的纸箱和一辆自行车；`sz`：城中村出租屋——瓷砖地、上下铺、电饭煲、窗外晾着衣服
2. 共享办公：长桌、懒人沙发、一块白板
3. 正经写字楼：地毯、玻璃会议室、绿植、Logo 墙
4. 一整层：前台、成排工位、玻璃隔断的机房
5. 总部：更大更气派，中庭一棵树，一尊镀金的创始人雕像（讽刺点），屋顶大招牌
地区点缀（各等级都带一两样）：`bay` → 乒乓球桌、康普茶桶、滑板、棕榈盆栽；`sz` → 茶台、发财树、招财猫、折叠行军床（996 时床上有人）。

**机房区**：`racks` 个机柜排成排，每个机柜上几颗 LED 随机闪烁。旁边是 **丹炉**：一个可爱的青铜小丹炉（三足、圆肚、镂空炉盖），用线缆连着机柜。`furnace` 非空时炉心发光、冒出发光小粒子，heat 越高光越亮、粒子越多、炉身轻微抖动；为 null 时熄火发灰。

**小人**（chibi 低模：圆头、短身、小手小脚，约 2.2 头身）：
- 按 role 区分服装：res 紫色白大褂、eng 蓝色卫衣、ops 橙色 T 恤、biz 深色西装、legal 灰西装加红领带；发型和肤色用 id 做稳定的伪随机
- 坐在各自工位打字（手臂小幅摆动、头偶尔晃），工位分配按 id 稳定，不要因为别人入职离职而换座位
- 每隔一阵随机有一两个人起身走到茶水区再走回来（简单直线/折线移动即可）
- mood < 35 的人头顶偶尔飘 💢/😫，mood > 75 的偶尔飘 😀/🔥（emoji 用 CanvasTexture sprite）
- 新出现的 id：从门口走进来并闪一下星星；消失的 id：抱着纸箱走出门口后移除
- **创始人**：一个明显不同的小人（黑色高领衫 + 牛仔裤，头顶一个小皇冠或发光标记），在白板前来回踱步

**长发眼镜男（cameo）**：及肩长发（深色）、黑框方眼镜、格子衬衫，比普通小人略高，跳跃有挤压拉伸。

## 工程要求
- 60fps：几何体和材质复用，devicePixelRatio 上限 2，页面不可见时暂停渲染
- `sync` 要做 diff，不要每次全部重建；等级或地区变化时允许重建房间
- 所有随机外观用基于 id 的确定性伪随机，不要 Math.random 决定长相
- 不要用后处理，不要引入除 three 以外的依赖
- 代码一个文件写完（建议 ≤ 1200 行），结构清晰，关键处写简短中文注释
- `dispose()` 要释放几何体/材质/贴图并移除监听

## 测试页
`scene-demo.html`（根目录，`<script type="module" src="/src/scene/demo.js">`）：全屏沙盘 + 左上角一排简易按钮：切换地区、等级 1~5、加人/减人（随机 role）、机柜 +/-、炼丹开关与 heat 滑块、night、alert、以及每一个 play 特效（cameo 的文字用「你再也吃不到 Chepole 了！！！」）。默认状态：sz、level 3、10 个员工、4 个机柜、炼丹中。
