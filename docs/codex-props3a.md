# 任务：为《炼丹大亨》3A 版做高精度道具库

《炼丹大亨》是一款 AI 创业讽刺模拟游戏（three.js）。3A 版的画面方向是**微缩景观 + 电影感**：像用微距镜头拍的实体沙盘——
材质真实（PBR）、倒角精细、细节丰富，但造型仍然干净、略带风格化（不追求照片级写实）。镜头有景深、环境光遮蔽、泛光和昼夜变化。

整体场景（城市、办公室、灯光、镜头、人物）由别人在写。你负责**道具库**：办公家具、街道设施、车辆、屋顶设备、摆设。

只允许创建/修改：`src/scene3a/props.js`、`src/scene3a/props-demo.js`、`props3a-demo.html`、`tools/props-check.mjs`。
**不要改 `src/scene3a/kit.js`**（缺功能就在总结里告诉我），也别动其它文件（有别人在同时改）。

## 起点
- 把 `src/scene/props.js`（旧版 51 个道具）复制成 `src/scene3a/props.js`，在它上面升级。旧的约定见 `docs/codex-props.md`。
- 建模工具箱换成了 `src/scene3a/kit.js`，**先把它从头到尾读一遍**。和旧版的区别：
  - `k.mat(color, o)` 现在是 PBR：`rough`、`metal`、`clear`（清漆层，车漆/釉面/钢琴漆）、`env`、`glow`/`glowK`、`alpha`、`side`，
    以及 **`tex`**（微表面提示：`wood` `fabric` `carpet` `metal` `plastic` `stone` `concrete` `asphalt` `plaster` `leather` `paper` `rubber` `foliage` `grass` `bronze` `paint` `brick`）。
    给了 `tex`，材质表面会有对应的细微凹凸和粗糙度起伏（世界空间三向投影，不需要 UV）。**几乎每个材质都应该给合适的 `rough`/`metal`/`tex`**，这是「真实感」的主要来源。
  - **`night`**：`k.mat('#fff3d0', { glow: '#ffd9a0', glowK: 0.15, night: 2.6 })` —— 白天自发光 0.15，天黑后场景会自动把它调到 2.6。所有灯、屏幕、招牌、车灯都要用它。
  - 新几何体：`k.capsule` 胶囊、`k.lathe` 旋转体、`k.tube` 管线、`k.extrude` 拉伸体、`k.plane`、`k.disc`；`k.put` 支持 `s/sx/sy/sz` 缩放。
  - `k.box` 的倒角 `r`：**几乎所有硬表面都要带倒角**（哪怕 0.008），高光才会沿着边缘走，这是微缩模型质感的关键。圆面分段数由工具箱按尺寸自动决定，不用操心。
- `prop(size, draw)` 的接口不变：`PROPS[name] = { size: [宽x, 深z, 高y], build(k, o) }`，`build` 返回一个 `THREE.Group`，原点在**底面中心**，正面朝 **+Z**。

## 统一的选项 `o`
- `o.brand`：公司品牌色（十六进制字符串），点缀用。
- `o.seed`：整数，用来在同一个道具里做变化（颜色、摆放、有没有某个小零件）。同一个 seed 必须得到同一个结果（用确定性的哈希，别用 Math.random）。
- `o.screen`：一个 `THREE.Material`，给了就用它当屏幕面（显示器、电视、广告屏）；没给就用默认的发光屏幕材质。
- `o.art`：一个 `THREE.Material`，给了就用它当画面（海报、广告牌）；没给就用纯色占位。
- 屏幕面/画面必须是**单独一个 `k.plane`**，并把这个网格记到 `g.userData.screen`（或 `g.userData.art`）上，UV 保持 0~1 整幅。

## 会动的东西
- 整体场景会把静态道具**按材质合批**成很少的几个网格。所以：需要动的零件放进一个子 `Group`，并设 `sub.userData.dynamic = true`（合批时会原样保留）。
- 动画写成 `g.userData.tick = (t, dt) => {…}`（t 是秒）。**tick 只能改带 `dynamic` 标记的子组**（道具的根组合批后就不存在了）。
- 需要独立变化的材质（比如红绿灯的三个灯）用 `k.mat(...).clone()`，并把克隆出来的材质放进 `g.userData.own = [...]`，场景销毁时会释放。
- 动画要克制：风扇转、鱼游、屏保闪、旗子飘、红绿灯换色、蒸汽上升之类。

## 尺度
世界单位≈米。人物是 Q 版比例，站立总高约 1.3，坐着头顶约 1.2。家具用接近真实的尺寸（桌面高 0.74，椅面高 0.46）。
车辆要比真实比例「胖短」一点才和 Q 版人物协调（见下表尺寸）。楼层高约 2.8。

## 性能
- 一个道具的三角面：小摆设 ≤ 6000，家具 ≤ 15000，车辆 ≤ 20000，树 ≤ 14000，大型（塔吊、玻璃会议室）≤ 40000。
- 一个道具用到的**不同材质**尽量少（同色同质感就复用同一个 `k.mat` 调用），这样合批后 draw call 才少。
- 不要用贴图、不要用 `Math.random`、不要创建灯光（Light）对象。

## 演示页
`props3a-demo.html` + `src/scene3a/props-demo.js`：用 Vite 开发服务器打开（`<script type="module" src="/src/scene3a/props-demo.js">`）。
- 把所有道具按类别排成网格摆在地面上，每个下面一个文字标签（CSS2D 或 Sprite 都行）；OrbitControls；`RoomEnvironment` 当环境光；一盏带阴影的平行光；ACES 色调映射。
- 右上角几个按钮：白天/夜晚（夜晚时把 `k.nightMats` 里每个材质的自发光调到夜间值，并把环境调暗）、换品牌色、换 seed。
- 每帧调用所有道具的 `userData.tick`，并让车辆的 `userData.wheels` 转起来。

## 自测（必须做）
`tools/props-check.mjs`（`node tools/props-check.mjs`）：在 Node 里用真的 kit 逐个构建所有道具（seed 取 0~3 各一次），检查：
1. 不抛错；2. 包围盒在尺寸包络的 ±12% 以内、底面在 y≈0；3. 三角面不超预算；4. 不同 seed 的结果是确定的（同 seed 构建两次三角面数相同）；
5. 用 `bake()` 合批后不报错，并统计合批后的网格数；6. 列出每个道具的 三角面 / 材质数 / 合批后网格数 / 是否有 tick。
最后输出 `PROPS OK <数量>`。

最后用几句话总结：一共多少个道具、哪些你觉得做得不够好、kit 还缺什么。
